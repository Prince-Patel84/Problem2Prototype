# 🎨 Problem2Prototype (P2P) Asset Guidelines

Place your Canva-created images in this `docs/` directory:
1. `banner.png`: GitHub README Hero Banner (Recommended size: 1280 x 640 px or 1200 x 400 px).
2. `logo.png`: Square Logo / App Icon (Recommended size: 512 x 512 px).
3. `architecture.png`: End-to-End Workflow Diagram.
4. `screenshot.png`: Web Studio UI Screenshot.
